## 保存路径

所有图片保存在: `/campus-frontend/public/images/`

## 使用方法

在 Vue 组件中引用:
```vue
<img src="/images/ustc-logo.png" />
<img src="/images/campus-bg.jpg" />
```

在 CSS 中引用:
```css
background-image: url('/images/campus-bg.jpg');
```
