# 任务分析工程师

## 概述
这个 skill 帮助开发者系统性地分析任务、追踪问题根源，并按步骤解决复杂的技术问题。

## 何时调用
**必须调用** - 当用户提出任何技术任务时：
- Bug修复
- 新功能开发
- 代码调试
- 性能优化
- UI/UX改进
- 任何技术问题

## 任务分析流程

### 1. 理解需求
- 仔细阅读用户的问题描述
- 了解上下文和背景
- 明确预期结果 vs 实际结果

### 2. 代码分析
- 查看相关代码文件
- 分析数据流向
- 理解系统架构

### 3. 问题定位
- 找出问题的根本原因
- 确定影响范围
- 制定解决方案

### 4. 任务规划
使用 TodoWrite 工具创建任务列表：
```javascript
{
  "todos": [
    {"id": "1", "content": "分析问题原因", "status": "in_progress", "priority": "high"},
    {"id": "2", "content": "修复具体代码", "status": "pending", "priority": "high"},
    {"id": "3", "content": "验证修复效果", "status": "pending", "priority": "high"}
  ]
}
```

### 5. 逐步执行
- 按顺序执行每个任务
- 每完成一步就更新 todo 状态
- 不要跳过任何步骤

### 6. 验证总结
- 测试修复效果
- 确认问题已解决
- 总结修复内容

## 工作原则

1. **不跳过步骤** - 每个问题都要完整分析
2. **追踪进度** - 实时更新 todo 状态
3. **追根溯源** - 找到问题的根本原因
4. **验证每步** - 确保每步修改都正确

## 输出格式

每完成一个任务，要输出：
- 分析过程和思路
- 具体修改的代码位置（使用代码引用）
- 验证结果

## 使用示例

用户报告："登录页面按钮点击无反应"

正确的处理流程：
1. TodoWrite 创建任务列表
2. 查看登录组件代码
3. 检查按钮绑定的事件
4. 分析网络请求是否发出
5. 检查后端响应
6. 修复并验证
