# 基于 Agent 的高校校园智能事务处理平台 —— 原型图说明

**版本：** 1.0  
**日期：** 2026年3月  
**说明：** 本文档以语言描述各页面的原型布局与交互逻辑，与现有项目视觉风格保持一致，供前端开发参考。

## 一、设计规范说明

### 1.1 整体视觉风格

本项目为**中国科学技术大学校园一站式平台**，所有新增页面须与现有系统风格保持一致。

- **主品牌色（科大蓝）：**
  - 主色 `#004191`，浅色变体 `#1a5cb8`，深色变体 `#003170`
  - 渐变：`linear-gradient(135deg, #004191 0%, #1a5cb8 100%)`
- **背景色：** `#F5F7FA`（全局页面背景）
- **卡片背景：** `#FFFFFF`，轻度阴影 `0 4px 20px rgba(0, 0, 0, 0.05)`
- **文字颜色：** 主文字 `#303133`，次级 `#606266`，占位符 `#909399`
- **圆角：** 小 8px，中 12px，大 16px（变量 `--ustc-radius-sm/md/lg`）
- **毛玻璃卡片：** 背景 `rgba(255, 255, 255, 0.85)`，边框 `rgba(255, 255, 255, 0.3)`
- **字体：** 系统默认无衬线体（`-apple-system, BlinkMacSystemFont, Segoe UI`）
- **组件库：** Element Plus，主题色通过 CSS 变量覆盖为科大蓝（`--el-color-primary: #004191`）
- **卡片交互：** 悬停时 `transform: translateY(-2px)` + 阴影加深，过渡时间 0.3s

### 1.2 品牌元素

- **USTC Logo：** `/images/ustc-logo.png`，出现在登录页、侧边栏、顶部导航栏
- **背景水印：** 首页内容区使用梅花图案水印（`.bg-watermark > .watermark-plum`），透明度极低
- **校徽标识：** 顶部导航栏右侧区域展示"USTC"文字 + 小校徽图标（`.ustc-badge-header`）

### 1.3 整体布局约定

**整体框架（MainLayout）：**
- 左侧：可折叠侧边栏，展开 220px / 折叠 72px，毛玻璃背景效果
- 右侧顶部：固定 Header（60px），含页面折叠控制 + 面包屑 + 用户信息
- 右侧内容区：`#F5F7FA` 背景，内容自适应宽度

**侧边栏细节：**
- 顶部 Logo 区（展开态：USTC 图标 + "一站式平台" 或 "管理后台"）
- `el-menu` 菜单，透明背景，激活项使用科大蓝渐变（文字变白）
- 支持二级菜单折叠（`el-sub-menu`）：二手交易下设"逛逛市场/我的发布/我的收藏"；宿舍管理下设"宿舍信息/报修申请/报修管理/宿舍管理"
- 消息中心菜单项图标上叠加 `Badge` 组件显示未读数

**顶部 Header 细节：**
- 左侧：折叠/展开图标（Fold/Expand 切换）+ `el-breadcrumb`（一级"首页" + 二级当前页）
- 右侧（从左到右）：
  - 管理端/用户端切换按钮（仅 `ROLE_ADMIN` 用户可见）
  - 校徽标识区（小 USTC logo + "USTC"）
  - 用户头像 + 昵称 + 下拉菜单（个人中心 / 修改密码 / 退出登录）

### 页面 1：登录页（Login）

**路由：** `/login`

**布局描述：**

左右双栏布局，无顶部导航，全屏高度占满。

**左栏（约 50% 宽，背景为校园实景图）：**

- 左上：USTC 校徽 + "中国科学技术大学" 文字标识（`.ustc-badge`）

  - 大标题："校园一站式平台"，白色，宽字重
  - 副标题："University of Science and Technology of China"，灰白色
  - 特性列表（4 项横排）：🏠 宿舍管理  🔄 二手交易  📍 失物招领  🗺️ 校园导航

**右栏（约 50% 宽，白色背景）：**
- 垂直居中的表单容器（宽度 380px，无卡片边框，直接白底）
- 顶部：USTC 校徽图标（居中）
- 标题："统一身份认证"（黑色粗体，字号 22px）
- 副标题："CAS Unified Identity Authentication"（灰色，字号 13px）
- `el-form` 表单（label 隐藏）：
  - 用户名输入框：`prefix-icon="User"`，`placeholder="请输入用户名"`，`size="large"`
  - 密码输入框：`prefix-icon="Lock"`，`type="password"`，右侧切换明文，`size="large"`

**交互说明：**
- 登录成功跳转 `/`（首页），期间按钮显示 Loading 状态（`loading` prop）

### 页面 4：智能助手页（Agent Chat）

**路由：** `/agent`

**布局描述：**

使用主布局框架（MainLayout），内容区再分为三栏。整体配色沿用科大蓝体系。

**左栏（会话历史面板，宽 220px，背景 `#F5F7FA`，右边框 1px `#e4e7ed`）：**
- 顶部："+ 新建对话" `el-button`（`type="primary" plain`，宽度 100%）
- 会话列表（`.session-list`）：
  - 每项：会话图标（Chat 图标，灰色）+ 会话标题文字（最多显示 2 行，字号 13px）+ 时间（极小字）
  - 当前激活会话：左侧蓝色 3px 竖线边框 + 背景 `rgba(0,65,145,0.06)`
  - 悬停态：背景 `rgba(0,65,145,0.04)`

**中栏（主对话区，自适应宽度，背景 `#FFFFFF`）：**

- **顶部会话标题栏（高度 52px，底边框分隔）：**
  - 左：机器人图标 + 会话标题
  - 右：清空对话按钮（`el-button text`，图标 Delete）

- **消息区（可滚动，占满高度，内边距 16px）：**

  **⚠️ 头像与气泡对齐规则（必须遵守）：**
  - **Agent 回复（左对齐）：** 左侧机器人头像（科大蓝背景，白色机器人图标，`el-avatar size=32`）→ 右侧白色气泡（边框 `1px solid #e4e7ed`，圆角 12px）
  - **用户消息（右对齐）：** 左侧科大蓝气泡（背景 `#004191`，白色文字，圆角 12px）→ 右侧用户头像（显示真实头像，fallback 为姓名首字，`el-avatar size=32`）
  - 绝不允许用户消息出现在左侧

  **Agent 回复内容结构（四区域规范）：**
  1. **自然语言解释区：** 纯文字段落，口语化说明任务处理结果
  2. **结构化结果卡片区（仅任务完成时显示）：**
     - **工单卡片：** 顶部蓝色小标签"报修工单" + 工单号（粗体）+ 故障类型 + 状态 `el-tag` + 提交时间 + "查看工单"按钮
     - **商品推荐卡片：** "推荐商品"标签 + 商品图 + 标题 + 红色价格 + 推荐理由 `el-tag` + "查看详情"按钮
     - **路线卡片：** 起点→终点（箭头分隔）+ 距离 + 预计时间 + **"查看地图"按钮**（点击跳转导航页并自动加载路线）
     - **失物匹配卡片：** 物品名 + 颜色标签 + 地点 + 相似度进度条 + "发消息"按钮 + "前往寻物公告"/"前往招领公告"按钮
  3. **推荐追问区（每轮任务完成后动态生成，不在追问过程中显示）：**
     - 3~4 个 `el-tag`（`type="info" effect="plain" size="small"`，带指针样式）横向排列在 Agent 回复气泡下方
     - 内容由后端根据当前意图和结果动态生成（不能固定写死）
     - 示例（报修完成后）：`查看工单状态` | `报修其他设备` | `联系宿管`
     - 示例（导航完成后）：`查看路线详情` | `换骑行方案` | `附近还有什么`
     - 示例（失物完成后）：`查看相似招领` | `补充丢失时间` | `联系管理员`
     - 点击后自动填充并立即发送该文本，开启下一轮对话
  4. **跳转操作按钮区：** 如"前往二手市场""查看宿舍工单"等 `el-button plain`，与页面其他跳转链接样式一致

  **工具调用状态行（居中，灰色 12px 小字）：**
  - 状态前缀图标：Loading 旋转图标（进行中）/ SuccessFilled 绿色图标（完成）
  - 文字示例："正在搜索二手商品…" / "✅ 已提交报修工单"

  **Loading 气泡：** 三点跳动动画（左对齐，机器人头像旁）

- **底部输入区（高度自适应，顶边框分隔，内边距 12px）：**
  - **输入框区域：** `el-input type="textarea" :autosize="{min:1, max:4}"`，圆角，无静态功能卡片
  - 右侧：发送按钮（`el-button type="primary" circle`，Paper Plane 图标），Enter 键发送，Shift+Enter 换行
  - **注意：** 去除原有输入框上方的静态"快捷指令卡片"，不再展示固定预设问题

**右栏（上下文面板，宽 280px，背景 `#F5F7FA`，左边框分隔）：**

三个 `el-collapse` 折叠面板：

1. **识别结果（默认展开）：**
   - "意图"行：左标签 + 右 `el-tag`（DORM_REPAIR → 蓝色，SECONDHAND_SEARCH → 绿色，NAVIGATION → 橙色，LOSTFOUND_LOST/FOUND → 红色）
   - "置信度"行：`el-progress type="line"` 进度条（高置信度绿色，中橙色，低红色）

2. **已提取参数：**
   - `el-descriptions` 组件（两列），参数名：参数值形式
   - 已填充的参数：正常黑色文字
   - 待填充的（缺失）参数：红色文字 + 警告图标

3. **执行结果（工具返回后显示）：**
   - 根据工具类型渲染对应卡片（圆角 12px，背景白色，细边框），内容同中栏结果卡片

#### Agent 深链自动加载机制

当导航页通过 Agent 结果卡片跳转时，URL 格式为：
```
/navigation?from=agent&origin=三号宿舍楼&dest=图书馆&mode=walking
```

**`Navigation.vue` 的 `onMounted` 处理逻辑：**
1. 读取 `route.query` 中的 `from`、`origin`、`dest`、`mode` 参数
2. 若 `from === 'agent'`，自动将表单出发地/目的地填入
3. 立即触发路线规划请求（`POST /api/navigation/plan`）
4. 页面进入"加载中"状态，路线返回后切换为"路线就绪"状态
5. 对用户而言：点击 Agent 路线卡片 → 导航页自动呈现完整路线，无需手动操作

## 五、关键交互状态说明

### 5.1 Agent 响应中的 Loading 状态

- 发送后：输入框 disabled，发送按钮 loading 状态，消息区底部出现三点跳动气泡
- 大模型推理中：右侧面板"识别结果"区域出现 el-skeleton 骨架
- 工具调用时：聊天区插入居中状态行（`el-icon loading` + 灰色小字，如"正在搜索二手商品…"）
- 完成时：状态行图标变为 `SuccessFilled`（绿色），气泡替换为正式回复，右侧面板更新结果卡片

### 5.2 Agent 追问状态

- Agent 追问气泡底部内嵌快捷输入组件（非独立输入框）：
  - 补充宿舍号：`el-input size="small"` 行内输入 + 确认按钮
  - 选择故障类型：`el-select size="small"` 嵌入气泡内
- 用户操作后自动提交，继续流程（追问最多 3 轮后降级为普通文字提示）

### 5.3 空状态

- 延用 `EmptyState.vue` 组件
- 新增 Agent 特有场景文案："开始一段新对话，告诉我你的校园事务需求"（配机器人插图）

### 5.4 管理端与用户端切换

- 仅 `ROLE_ADMIN` 用户顶部导航栏显示模式切换按钮（`Switch` 图标 + "管理端"/"用户端"）
- 切换后侧边栏菜单项更新：管理端显示"二手审核/失物招领管理/系统公告/账号管理"
- Logo 区文字随模式切换："一站式平台" ↔ "管理后台"
- 智能助手入口在管理端模式下隐藏
