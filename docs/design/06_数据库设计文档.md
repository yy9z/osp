# 基于 Agent 的高校校园智能事务处理平台 —— 数据库设计文档

**版本：** 1.0  
**日期：** 2026年3月  
**数据库：** MySQL 8.0+  
**字符集：** utf8mb4  
**排序规则：** utf8mb4_unicode_ci  

---

## 一、设计原则

1. 主键统一使用 `BIGINT AUTO_INCREMENT`，命名为 `id`。
2. 所有表包含创建时间 `created_at` 和更新时间 `updated_at`，类型为 `DATETIME`，更新时间由 MySQL 触发器或应用层维护。
3. 逻辑删除字段 `is_deleted TINYINT(1) DEFAULT 0`，不做物理删除。
4. 外键约束在应用层维护，数据库层不建物理外键（避免级联删除风险）。
5. 金额字段使用 `DECIMAL(10,2)` 而非 `FLOAT/DOUBLE`，避免浮点精度问题。
6. 状态字段使用 `TINYINT` 或 `VARCHAR(20)` 存储枚举值，并在代码层维护枚举映射。

## 二、ER 图说明（文字版）

主要实体及关系：

- `user`：系统用户（学生、管理员）
- `dorm_building`：宿舍楼
- `dorm_room`：宿舍房间
- `dorm_assignment`：入住记录（user ↔ dorm_room）
- `repair_order`：报修工单（user → dorm_room）
- `secondhand_item`：二手商品（user 发布）
- `secondhand_favorite`：商品收藏（user ↔ secondhand_item）
- `lost_item`：**寻物公告**（失主发布"我丢了"的公开帖子，同时支持"我的失物"个人视图）
- `found_item`：**招领公告**（拾主发布"我捡到了"的公开帖子，同时支持"我的招领"个人视图）
- `lost_match`：失物匹配结果（lost_item ↔ found_item）
- `campus_poi`：校园 POI 数据
- `nav_favorite`：用户收藏地点（user ↔ campus_poi）
- `message`：站内消息（user → user）
- `notification`：系统通知（→ user）
- `agent_log`：Agent 调用日志（user）
- `agent_session`：Agent 会话记录

**失物招领 4 Tab 与表的对应关系：**

| 前端 Tab 名称 | 查询来源 | 过滤条件 |
|-------------|----------|----------|
| 寻物公告 | `lost_item` | `is_deleted=0`（全部记录） |
| 招领公告 | `found_item` | `is_deleted=0`（全部记录） |
| 我的失物 | `lost_item` | `user_id=当前用户 AND is_deleted=0` |
| 我的招领 | `found_item` | `user_id=当前用户 AND is_deleted=0` |

### 3.1 用户表（user）

> 存储系统用户基本信息。

```sql
CREATE TABLE `user` (
    `id`            BIGINT          NOT NULL AUTO_INCREMENT COMMENT '用户ID',
    `username`      VARCHAR(50)     NOT NULL UNIQUE COMMENT '用户名/学号',
    `password`      VARCHAR(255)    NOT NULL COMMENT '密码（BCrypt 加密）',
    `nickname`      VARCHAR(50)     NOT NULL COMMENT '昵称',
    `avatar_url`    VARCHAR(500)    COMMENT '头像URL',
    `role`          VARCHAR(20)     NOT NULL DEFAULT 'ROLE_USER' 
                    COMMENT '角色: ROLE_USER/ROLE_DORM_ADMIN/ROLE_ADMIN',
    `phone`         VARCHAR(20)     COMMENT '手机号',
    `email`         VARCHAR(100)    COMMENT '邮箱',
    `is_deleted`    TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '逻辑删除',
    `created_at`    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP 
                    ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    INDEX `idx_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 3.8 失物记录表（lost_item）

> 存储「寻物公告」数据，即失主发布的“我丢了”信息。
> 
> **前端 4 Tab 映射关系：**
> - 「寻物公告」 Tab = `SELECT * FROM lost_item WHERE is_deleted=0`（全校公共信息池）
> - 「我的失物」 Tab = `SELECT * FROM lost_item WHERE user_id=? AND is_deleted=0`（个人管理）

```sql
CREATE TABLE `lost_item` (
    `id`            BIGINT          NOT NULL AUTO_INCREMENT,
    `user_id`       BIGINT          NOT NULL COMMENT '失主用户ID',
    `item_name`     VARCHAR(100)    NOT NULL COMMENT '物品名称',
    `color`         VARCHAR(30)     COMMENT '颜色',
    `lost_location` VARCHAR(200)    COMMENT '丢失地点描述',
    `lost_time`     DATETIME        COMMENT '丢失时间',
    `description`   TEXT            COMMENT '详细描述',
    `image_urls`    JSON            COMMENT '图片URL列表',
    `status`        VARCHAR(20)     NOT NULL DEFAULT 'SEARCHING'
                    COMMENT '状态: SEARCHING(寻找中)/FOUND(已找回)/CLOSED(已关闭)',
    `matched_found_id` BIGINT       COMMENT '最终匹配到的拾物记录ID',
    `source`        VARCHAR(20)     NOT NULL DEFAULT 'MANUAL'
                    COMMENT '来源: MANUAL/AGENT（是否通过智能助手提交）',
    `is_deleted`    TINYINT(1)      NOT NULL DEFAULT 0,
    `created_at`    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP 
                    ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    INDEX `idx_user_id` (`user_id`),
    INDEX `idx_status` (`status`),
    FULLTEXT INDEX `ft_name_desc` (`item_name`, `description`, `color`, `lost_location`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='寻物公告表（失主发布「我丢了」的公开信息）';
```

## 四、索引设计说明

| 表 | 索引字段 | 目的 |
|----|---------|------|
| `user` | `username` | 登录时快速查找 |
| `repair_order` | `user_id`, `status` | 按用户/状态筛选工单 |
| `secondhand_item` | `status`, `category`, `price` | 首页/分类/价格查询 |
