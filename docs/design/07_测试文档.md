**版本：** 2.0

## 一、测试策略

### 1.1 测试目标

- 验证 Agent 意图识别与参数提取的准确性。
- 验证各业务工具调用的正确性和异常处理能力。
- 验证 Agent 导航深链跳转机制的完整性和一致性。
- 验证失物招领 4 子模块（寻物公告/招领公告/我的失物/我的招领）的功能完整性。
- 验证动态推荐追问功能的上下文相关性。
- 验证前端交互流程的完整性和用户体验。
- 验证系统安全性（权限、注入防护）。

### 1.2 测试类型

| 类型 | 范围 | 工具 |
|------|------|------|
| 单元测试 | Service 层、工具类 | JUnit 5 + Mockito |
| 集成测试 | Controller + Service + DB | Spring Boot Test |
| Agent 场景测试 | 端到端 Agent 调用链 | 手动测试 + 脚本 |
| 导航深链测试 | Agent → 导航页链路 | 手动测试 |
| 失物招领模块测试 | 4 Tab + Agent 发布 | 手动测试 |
| 动态追问测试 | followUpSuggestions 生成 | 手动测试 |
| 前端功能测试 | 页面功能、交互流程 | 手动测试 |
| 安全性测试 | API 鉴权、输入校验 | 手动 + cURL |
| 性能测试 | Agent 响应时间、并发 | 手动测量 |

### 场景组 A：宿舍报修

#### TC-A-001：完整信息一次性报修

**测试场景：** 用户一次性给出所有必要信息，Agent 无需追问。

**输入：**
> "我宿舍 3-101 的空调坏了，不制冷，帮我报修"

**预期行为：**
1. 意图识别：`DORM_REPAIR`，置信度 ≥ 0.85
2. 参数提取：`fault_type=空调`，`dorm_no=3-101`，`description=不制冷`
3. 无追问，直接调用 `dorm_repair` 工具
4. 返回工单卡片：工单号不为空，状态为 `PENDING`

**预期回复样例：**
> "已为你提交宿舍报修工单，工单编号 WX20260309001，故障类型：空调，状态：待处理。如有进展，系统会自动通知你。"

**验收标准：** 工单写入数据库，`source=AGENT`

---

#### TC-A-002：缺少宿舍号追问

**测试场景：** 用户描述了故障但未提供宿舍号，且用户未绑定宿舍信息。

**输入：**
> "我宿舍灯坏了"

**预期行为：**
1. 意图识别：`DORM_REPAIR`
2. 参数提取：`fault_type=灯`，`dorm_no=null`
3. 追问："好的，请问你的宿舍号是？"（右侧面板"待补充：宿舍号"标红）

**补充输入：**
> "203"

**预期行为：**
4. 合并参数：`dorm_no=203`
5. 提交工单，返回工单卡片

**验收标准：** 多轮对话正常结束，最终提交成功

---

#### TC-A-003：查询报修工单状态

**输入：**
> "我最近提交的报修处理了吗"

**预期行为：**
1. 意图识别：`REPAIR_QUERY`
2. 调用工单查询工具，查询当前用户最近工单
3. 返回工单列表卡片，每张显示状态

---

#### TC-A-004：不合法故障类型

**输入：**
> "我宿舍发生了神秘现象，帮我报修"

**预期行为：**
1. 意图识别：`DORM_REPAIR`
2. `fault_type` 提取为"其他"或"神秘现象"
3. 提交工单时，`fault_type` 归类为"其他"
4. 不报错，正常提交

### 场景组 C：失物招领匹配

### 3.1 测试框架

### 3.2 关键测试类

#### IntentServiceTest

```java
@ExtendWith(MockitoExtension.class)
class IntentServiceTest {

    @Mock
    private LlmClient llmClient;

    @InjectMocks
    private IntentService intentService;

    @Test
    void testIdentifyDormRepairIntent() {
        when(llmClient.chat(anyList()))
            .thenReturn("{\"intent\": \"DORM_REPAIR\", \"confidence\": 0.92}");

        IntentResult result = intentService.identify("我宿舍空调坏了");

        assertEquals("DORM_REPAIR", result.getIntent());
        assertTrue(result.getConfidence() >= 0.85);
    }

    @Test
    void testIdentifyUnknownIntent() {
        when(llmClient.chat(anyList()))
            .thenReturn("{\"intent\": \"UNKNOWN\", \"confidence\": 0.55}");

        IntentResult result = intentService.identify("帮帮我");
        assertEquals("UNKNOWN", result.getIntent());
    }
}
```

#### SlotFillingServiceTest

```java
@Test
void testExtractDormRepairSlots() {
    when(llmClient.chat(anyList()))
        .thenReturn("{\"slots\": {\"fault_type\": \"空调\", \"dorm_no\": \"3-101\"}}");

    SlotResult result = slotFillingService.extract("我宿舍3-101空调坏了", "DORM_REPAIR");

    assertEquals("空调", result.getSlots().get("fault_type"));
    assertEquals("3-101", result.getSlots().get("dorm_no"));
    assertTrue(result.getMissingSlots().isEmpty());
}

@Test
void testMissingSlot() {
    when(llmClient.chat(anyList()))
        .thenReturn("{\"slots\": {\"fault_type\": \"灯\"}, \"missing\": [\"dorm_no\"]}");

    SlotResult result = slotFillingService.extract("我宿舍灯坏了", "DORM_REPAIR");

    assertTrue(result.getMissingSlots().contains("dorm_no"));
}
```
