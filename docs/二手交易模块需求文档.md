# 二手交易模块需求文档

## 1. 模块概述

二手交易模块是"中科大一站式平台"的核心功能之一，旨在为校内外用户提供一个安全、便捷的二手物品交易渠道。模块采用"买家市场"与"个人中心"双核心架构，形成完整的交易闭环。

### 1.1 设计理念

- **主题色**: #004191 (科大蓝)
- **风格**: Bento Grid (便当盒) 风格，16px 大圆角，柔和阴影
- **导航**: 侧边栏二级菜单

---

## 2. 功能架构

```
二手交易模块
├── 逛逛市场 (Market)
│   ├── 分类筛选 (教材、数码、电器、生活、其他)
│   ├── 关键词搜索
│   ├── 商品列表 (卡片式布局)
│   ├── 收藏功能
│   └── 商品详情
│       ├── 大图展示
│       ├── 卖家信息
│       └── 联系卖家
│
└── 我的发布 (My Store)
    ├── 发布商品
    ├── 商品管理
    │   ├── 编辑
    │   ├── 标记已售
    │   └── 下架
    └── 我的收藏
```

---

## 3. 业务流程

### 3.1 发布商品流程

```
用户登录 → 填写商品信息 → OSS多图上传 → 提交审核
                                            ↓
                                   状态: AUDITING (审核中)
                                            ↓
                                   管理员审核 (可选)
                                            ↓
                                   状态: ACTIVE (在售)
```

### 3.2 购买咨询流程

```
浏览商品 → 查看详情 → 点击"联系卖家"
                                    ↓
                          跳转到消息中心 + 自动生成咨询消息
```

### 3.3 交易完成流程

```
卖家标记"已售出" → 状态变为 SOLD → 自动推送系统通知到首页动态
```

## 4. 数据模型

### 4.1 二手商品表 (secondhand)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 商品ID (主键) |
| title | VARCHAR(100) | 商品标题 |
| description | TEXT | 商品描述 |
| price | DECIMAL(10,2) | 商品价格 |
| category | VARCHAR(20) | 分类 |
| images | VARCHAR(500) | 图片URL列表 (JSON) |
| condition | VARCHAR(20) | 新旧程度 |
| status | ENUM | 状态: AUDITING/ACTIVE/SOLD |
| seller_id | BIGINT | 卖家ID |
| view_count | INT | 浏览次数 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 4.2 商品分类

| 值 | 说明 |
|----|------|
| BOOKS | 教材 |
| DIGITAL | 数码 |
| APPLIANCE | 电器 |
| DAILY | 生活 |
| OTHER | 其他 |

### 4.3 商品状态

| 值 | 说明 |
|----|------|
| AUDITING | 审核中 |
| ACTIVE | 在售 |
| SOLD | 已售出 |

### 4.4 新旧程度

| 值 | 说明 |
|----|------|
| NEW | 全新 |
| LIKE_NEW | 几乎全新 |
| GOOD | 有明显使用痕迹 |

### 4.5 收藏表 (goods_favorite)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 收藏ID |
| user_id | BIGINT | 用户ID |
| goods_id | BIGINT | 商品ID |
| create_time | DATETIME | 收藏时间 |

---

## 5. 页面结构

### 5.1 逛逛市场

- **路由**: `/secondhand?tab=market`
- **布局**: 左侧分类侧边栏 + 右侧商品网格
- **每行**: 4 个商品卡片
- **图片比例**: 16:9, object-fit: cover

### 5.2 我的发布

- **路由**: `/secondhand?tab=mystore`
- **布局**: 顶部操作栏 + 商品列表
- **状态筛选**: 全部/审核中/在售/已售出

### 5.3 商品详情

- **路由**: `/secondhand/:id`
- **布局**: 左侧大图 + 右侧信息

## 6. 接口列表

### 6.1 商品接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/secondhand/list | 商品列表 (分页、筛选、排序) |
| GET | /api/secondhand/{id} | 商品详情 |
| POST | /api/secondhand/publish | 发布商品 (需登录) |
| GET | /api/secondhand/my | 我的发布列表 (需登录) |
| PUT | /api/secondhand/{id}/sold | 标记已售 (需登录) |
| DELETE | /api/secondhand/{id} | 下架商品 (需登录) |

### 6.2 收藏接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/secondhand/{id}/favorite | 收藏商品 |
| DELETE | /api/secondhand/{id}/favorite | 取消收藏 |
| GET | /api/secondhand/favorites | 我的收藏列表 |
| GET | /api/secondhand/{id}/favorite/status | 检查是否已收藏 |
