# 系统架构讲解稿（可口述 60-90 秒）

我们的系统采用前后端分离架构，并在传统业务系统上增加了 Agent 编排层，整体可以分成四层：

1. 交互层（Frontend）
- 基于 Vue3 + Element Plus。
- 负责承接用户操作，包括页面导航、表单输入、消息对话和结果展示。

2. 智能编排层（Agent Core）
- 这是系统的关键增强层。
- 负责把自然语言请求转成可执行任务，核心流程是：意图识别 -> 槽位补全 -> 工具选择 -> 结构化响应。

3. 业务服务层（Backend Services）
- 基于 Spring Boot + MyBatis。
- 包含二手交易、失物招领、宿舍管理、消息中心、导航等业务模块。
- Agent 最终会调用这些业务服务执行真实操作。

4. 数据与基础设施层（Data & Infra）
- MySQL 存储核心业务数据。
- Redis 承接会话与缓存能力。
- 同时对接对象存储和地图等外部服务。

一句话总结：
这个架构的价值在于，保留原有业务模块稳定性，同时用 Agent 做统一入口和跨模块协同，既能快速落地，也便于后续扩展。
